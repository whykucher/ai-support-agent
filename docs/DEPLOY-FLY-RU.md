# Переезд на Fly.io — по шагам

Зачем: на бесплатном Render сервис засыпает через 15 минут тишины, и следующий
посетитель ждёт около 50 секунд на пустой странице. Для портфолио, которое
открывают по ссылке из отклика, это и есть всё первое впечатление.

На Fly машина тоже останавливается, когда её не трогают, но поднимается за
пару секунд, а не за пятьдесят.

## Про деньги — прочитай до регистрации

**Карту Fly требует обязательно**, даже если платить не собираешься.

Тарификация — за **время работы машины**. Остановленная машина не стоит ничего.
В `fly.toml` стоит `auto_stop_machines = "stop"` и `min_machines_running = 0`,
то есть при отсутствии посетителей счёт нулевой.

Что стоит денег, если это включить:

| | |
|---|---|
| машина `shared-cpu-1x` 512 МБ, если держать её всегда включённой | ~$3.30 в месяц |
| постоянный диск под базу | $0.15 за ГБ в месяц |
| исходящий трафик | $0.02–$0.12 за ГБ |

Портфолио с десятком заходов в день в эти деньги не попадает. Но если увидишь в
счёте что-то неожиданное — первым делом проверь, не включился ли
`min_machines_running = 1`.

## Шаг 1. Аккаунт

Регистрация и карта — только ты, я это сделать не могу.

1. <https://fly.io/app/sign-up>
2. Привяжи карту в Billing.

## Шаг 2. Вход в CLI

`flyctl` уже установлен в `C:\Users\whykucher\.fly\bin`. Открой **обычный
PowerShell** (не через меня — команде нужен интерактивный терминал) и выполни:

```bash
fly auth login
```

Откроется браузер, подтверди вход.

## Шаг 3. Занять имя приложения

Имена на Fly глобальные, поэтому `ai-support-agent` может быть занято. Эта
команда возьмёт готовый `fly.toml` и предложит имя:

```bash
fly launch --copy-config --no-deploy
```

Если имя занято — согласись на предложенное, оно попадёт в `fly.toml`.

## Шаг 4. Пароль к админке

Придумай свой и запомни — это пароль для `/admin`:

```bash
fly secrets set ADMIN_TOKEN=свой-длинный-пароль
```

## Шаг 5. Выложить

```bash
fly deploy
```

Первая сборка — несколько минут, дальше быстрее. Адрес будет вида
`https://<имя>.fly.dev`.

## Шаг 6. Проверить

```bash
fly status
```

И открыть сайт. Живая цепочка на главной, `/lab`, `/admin` и все шесть
демо-бизнесов должны работать так же, как на Render.

## Дальше, когда что-то поменяешь

```bash
fly deploy
```

Никаких галок в дашборде — в отличие от Render, где автодеплой выключен и
каждую сборку приходится запускать руками.

## Если надо откатиться

```bash
fly releases
fly deploy --image <образ из нужного релиза>
```

Render при этом остаётся живым и рабочим — удаляй его только когда убедишься,
что Fly держит нагрузку.
