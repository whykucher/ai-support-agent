# Личный сайт-портфолио

Один файл, `index.html`. Никакой сборки, никаких зависимостей — только шрифты
с Google Fonts. Открывается двойным кликом, работает где угодно.

---

## Что нужно заполнить перед публикацией

Открой `index.html` Блокнотом и найди эти места:

1. **Ссылка на Upwork.** В самом низу, в блоке `channels`, лежит закомментированная
   строка. Раскомментируй и подставь свой профиль:

   ```html
   <a href="https://www.upwork.com/freelancers/~ТВОЙ-ID" target="_blank" rel="noopener">Upwork profile →</a>
   ```

2. **Почта.** Сейчас стоит `hentajp5@gmail.com`. Если хочешь отдельный адрес для
   работы — поменяй в двух местах (`mailto:` и текст ссылки).

3. **Цифры в кейсе** (`0.6 s`, `20 automated checks`) взяты из реального замера
   демо. Если демо изменится — обнови их, иначе получится враньё, а на нём
   портфолио и горит.

Чего на сайте **намеренно нет**: количества лет опыта, числа клиентов и отзывов.
Я не стал их придумывать. Появятся настоящие — допишешь.

## Как выложить бесплатно

### Вариант 1. GitHub Pages (рекомендую)

Даёт адрес вида `whykucher.github.io` — короткий и солидный.

1. Создай на GitHub **новый** репозиторий с именем ровно `whykucher.github.io`
   (обязательно публичный).
2. Загрузи туда `index.html` — можно прямо через кнопку **Add file → Upload
   files** на сайте, командная строка не нужна.
3. Через минуту сайт откроется по адресу `https://whykucher.github.io`.

Если хочешь оставить его в этом же репозитории:

```powershell
cd "C:\Users\whykucher\Новая папка (4)\ai-support-agent"
git subtree push --prefix portfolio origin gh-pages
```

Потом в настройках репозитория: **Settings → Pages → Branch: gh-pages**.
Адрес будет `https://whykucher.github.io/ai-support-agent`.

### Вариант 2. Netlify Drop

<https://app.netlify.com/drop> — перетащи папку `portfolio` в окно браузера.
Сайт поднимется за десять секунд, без регистрации. Адрес будет случайный,
но его можно поменять в настройках.

### Свой домен

Стоит около $10 в год. Не обязателен: `whykucher.github.io` выглядит нормально
и ничего не стоит. Домен имеет смысл, когда пойдут первые заказы.

## Что где лежит в файле

| Секция | Что говорит клиенту |
|---|---|
| Заголовок + две дорожки | Проблема, которую он узнаёт в себе, и разница в цифрах |
| What I build | Четыре понятные вещи, без жаргона |
| A build you can open right now | Доказательство: живая ссылка и открытый код |
| How it goes | Снимает страх «отдам деньги и пропаду» |
| When not to hire me | Единственная секция, которая реально отличает тебя от сотни откликов |
| Contact | Одно действие |

Секцию **When not to hire me** не убирай, даже если рука тянется. Она вызывает
больше доверия, чем весь остальной текст: человек, который честно говорит, за
что не берётся, выглядит как тот, кто знает, за что берётся.
