Lab Client demo Ops

Three tools, running on this server.

Every button below makes a real request and returns a real result. Nothing is pre-recorded, nothing needs an account, and each run is written to the log you can see on the front page.

Page scraper

POST /api/lab/scrape

Fetches a public page and pulls out the parts a client usually wants: title, description, heading outline, contact details and the link graph. Private and loopback addresses are refused — a scraper that will fetch anything from inside your network is a security hole, not a feature.

Message classifier

POST /api/lab/classify

The same scoring the live agent runs on every conversation. It returns an intent, a lead score, the entities it found, and where the message would be routed. A complaint outranks a purchase in the same message, because that person needs a human first.

Try
Results appear here.

CSV cleaner

POST /api/lab/clean

Paste an export. It normalises each column by what the column is (emails lowercased, phone numbers stripped to digits), drops blank and duplicate rows, pads ragged ones, flags invalid emails, and hands the cleaned file back.

These are deliberately small. The point is not that scraping a page is hard — it is that each one is a real endpoint with error handling, input validation, rate limiting and a log entry behind it, which is the part that decides whether an automation survives contact with a real business.
